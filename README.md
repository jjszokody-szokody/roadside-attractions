# Roadside Gems
A clean, mobile-friendly single-page app for finding roadside attractions and oddities within 20 miles.

- **Nearby**: uses your location (or a typed place) to list attractions by distance, with "Show on map", details and directions.
- **Map**: auto-loads pins around you; search anywhere. Tap a pin for a detail sheet with address, hours, description, Wikipedia summary and links.
- **Quirky filter**: giant statues, world's-largest things, novelty architecture and more.

Live: hosted on GitHub Pages (see the repository's Pages settings for the current URL).

Data: OpenStreetMap (Overpass, Nominatim; ODbL), Wikidata (CC0), Wikipedia (CC BY-SA). No API keys required.
