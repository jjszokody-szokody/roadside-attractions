# ★ Roadside Oddities ★
A single-page, mobile-friendly web app for finding roadside attractions within 20 miles.
- **Nearby**: uses your location (or a typed place) to list attractions by distance, with Google Maps directions.
- **Map**: search anywhere and see attractions as map markers.
- **🤪 Quirky filter**: giant statues, world's-largest things, novelty architecture and more.

Data: OpenStreetMap (Overpass, Nominatim, ODbL), Wikidata (CC0), Wikipedia. No API keys required.
